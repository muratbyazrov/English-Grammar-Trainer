# English Grammar Trainer

Небольшое браузерное приложение для тренировки грамматики по вашим PDF.

## Что умеет

- вопросы идут по порядку, как в PDF (по номеру задания);
- показывает вопрос и ожидает ввод правильного слова/фразы;
- варианты `a/b/c` всегда отображаются на экране, как в книге;
- кнопка `Показать ответ` раскрывает правильный вариант;
- статистика по текущей сессии (верно/ошибок);
- режим Shadowing: приложение произносит фразу, слушает повтор через микрофон и оценивает совпадение;
- прогресс автоматически сохраняется в `localStorage` и восстанавливается после перезагрузки страницы.

## Запуск

Откройте файл `index.html` в браузере или поднимите локальный сервер:

```bash
# Из папки проекта:
python3 -m http.server 4173
```

Потом откройте:

- `http://localhost:4173/index.html`

Для Shadowing откройте приложение через `localhost` в Chrome или Edge и разрешите доступ к микрофону.

На macOS можно просто дважды нажать `start.command` в папке приложения. Не открывайте `index.html` напрямую: для страниц с адресом `file://` Chrome может запрашивать микрофон перед каждой фразой.

## Пересборка базы вопросов из PDF

```bash
python3 scripts/build_questions.py
```

Скрипт берёт:

- `english_grammar_exercises_with_answers_part_1.pdf`
- `ответы.pdf`

и обновляет `questions.js`.

## Структура кода

- `app.js` — подключение режимов, общие элементы интерфейса, обработчики событий и сборка снимка прогресса.
- `js/*-mode.js` — логика грамматики, словаря, Shadowing и теории. Зависимости передаются явно при создании режима.
- `js/learning-data.js` — темы, теория и переводы; `questions.js` и `vocabulary.js` — сгенерированные базы упражнений.
- `js/activity.js` — отложенные действия. При смене режима или вопроса таймеры отменяются; отменённые callbacks игнорируются.
- `js/speech.js` — синтез речи, выбор голоса и отмена озвучки. Распознавание речи находится в `js/shadowing-mode.js`.
- `js/progress.js` — чтение и запись `localStorage`. Сохранён ключ `english-grammar-trainer.progress.v2` и совместимость с сохранённым прогрессом остальных режимов.

Скрипты подключаются по порядку в `index.html`; сборщик и установка npm-зависимостей не нужны. Настройки озвучки грамматики и словаря независимы.

## Проверки

Нужен Node.js 18 или новее:

```bash
npm test
```

Тесты загружают скрипты из `index.html` и проверяют переключение режимов, таймеры, озвучку, восстановление прогресса и обработчики распознавания речи. DOM, часы и речевые API имитируются; реальный микрофон и качество распознавания проверяются вручную в браузере.
