# English Grammar Trainer

Небольшое браузерное приложение для тренировки грамматики по вашим PDF.

## Что умеет

- вопросы идут по порядку, как в PDF (по номеру задания);
- показывает вопрос и ожидает ввод правильного слова/фразы;
- варианты `a/b/c` всегда отображаются на экране, как в книге;
- кнопка `Показать ответ` раскрывает правильный вариант;
- статистика по текущей сессии (верно/ошибок);
- режим Shadowing: приложение произносит фразу, слушает повтор через микрофон и оценивает совпадение;
- в теории будущего времени режим «Наглядно»: смысл, ситуация, формула и пример открываются кнопкой «Далее»; «Следующая форма» переключает форму будущего времени, затем идёт мини-проверка; есть повтор текущего слайда, настройка устройства «уменьшить движение» отключает анимации;
- прогресс автоматически сохраняется в `localStorage` и восстанавливается после перезагрузки страницы.

Во всех режимах задание засчитывается в «верно», если выполнено без ошибок. Ошибка или пропуск учитывается один раз; исправление ответа и повторная тренировка того же задания не меняют оценку. Итоговый процент — доля верных среди верных и ошибочных заданий. 100% показывается только при отсутствии ошибок. Результаты отдельных заданий сохраняются при перезагрузке и сбрасываются при начале новой сессии.

## Запуск

Откройте файл `index.html` в браузере или поднимите локальный сервер:

```bash
# Из папки проекта:
python3 -m http.server 4173
```

Потом откройте:

- `http://localhost:4173/index.html`

Для Shadowing откройте приложение через `localhost` в Chrome или Edge и разрешите доступ к микрофону.

На macOS можно просто дважды нажать `start.command` в папке приложения. Не открывайте `index.html` напрямую: для страниц с адресом `file://` Chrome может запрашивать микрофон перед каждой фразой.

## Пересборка базы вопросов из PDF

```bash
python3 scripts/build_questions.py
```

Скрипт берёт:

- `english_grammar_exercises_with_answers_part_1.pdf`
- `ответы.pdf`

и обновляет `questions.js`.

Проверенные исправления опечаток, номеров и ключей ответов сохраняются в `scripts/grammar_corrections.json` и применяются при каждой пересборке. Если исправление больше не соответствует исходной базе или появляются повторяющиеся номера, сборка останавливается с ошибкой. В заданиях с двумя допустимыми формами после `like` принимаются оба указанных ответа. Для отсутствующего артикля или предлога вводите `-` или `–`.

## Структура кода

Краткая [карта проекта](ARCHITECTURE.md) показывает, где менять интерфейс, правила тренировки, прогресс и сохранения.

### Словарь Oxford 3000

Порядок вкладок: «Английский для IT», затем «Oxford 3000». В Oxford примеры необязательны: у простых слов они убраны и из тренировки, и из списка слов; в стартовой подборке оставлены только у `near`, `order` и `pay` для пояснения употребления. IT-примеры сохранены.

В разделе «Словарь» наборы «Oxford 3000» и «Английский для IT» переключаются кнопками сверху окна выбора. Все темы и подтемы выбранного набора видны сразу: нажатие на подтему или «Вся тема» начинает тренировку без вложенных экранов. При повторном открытии показывается набор текущей тренировки; перейти к другой теме можно одним нажатием. Полный список Oxford содержит 3313 карточек уровней A1–B2: одно слово может иметь разные части речи или уровень в разных значениях. Исходные 60 карточек и их идентификаторы сохранены. Новые карточки сгруппированы по темам; оставшиеся общие слова распределены по частям речи и алфавиту.

Можно тренировать весь набор, тему или подтему. Подход Oxford включает до 20 случайных слов; «Список слов» показывает весь выбранный раздел. Уровень и часть речи служат подсказками. Сохранённый порядок слов и результаты подхода восстанавливаются после перезагрузки. IT-темы сохраняют прежний состав и идентификаторы.

В выборе словарных тем у набора, каждой темы и подтемы показана полоса «Пройдено N из M». В обоих наборах слово считается пройденным после непустого ответа (включая ошибочный) или запроса озвучки-подсказки. Простое пролистывание прогресс не увеличивает и не засчитывает правильный ответ или закрепление ошибки. Открытие карточки или списка слов само по себе прогресс не увеличивает. Каждое слово учитывается один раз, независимо от повторных тренировок. Прогресс накапливается между подходами и сохраняется в `localStorage` текущего браузера; очистка данных сайта удалит его, автоматической синхронизации между устройствами нет. Для старых сохранений восстанавливаются известные пройденные слова из последнего подхода.

В обоих наборах полоса разделена на зелёную часть (пройденные слова без незакреплённых ошибок), красную (пройденные слова, оставшиеся в ошибках) и серый остаток (не пройдено). Например, при пяти верных и пяти ошибочных словах из десяти полоса наполовину зелёная и наполовину красная. После одного самостоятельного правильного ответа ошибочное слово становится зелёным. Доли считаются от всех слов раздела (в Oxford с учётом выбранного уровня), отдельно для подтемы, темы и набора; точные количества доступны при наведении и в доступном описании карточки. Используются существующие ID пройденных слов и ошибок, дополнительные копии словаря не сохраняются.

Кнопка «Сбросить прогресс» под карточкой раздела удаляет его отметки после подтверждения; можно сбросить отдельную подтему, целую тему или весь набор. После сброса полоса серая, список ошибок сохраняется. Фильтр Oxford применяется и к полосам, и к сбросу: при выбранном A2 «Только этот» удаляются только отметки A2. Результаты текущего подхода и других режимов при сбросе сохраняются.

В обоих наборах рядом с количеством слов темы или подтемы показано число слов с ошибками. Компактная кнопка «↻ Ошибки · N» в заголовке группы запускает повторение её ошибок; у самостоятельных тем IT эта кнопка находится под карточкой. Такая же кнопка у набора собирает ошибки всех его тем. В Oxford фильтр уровня применяется к счётчикам и повторению. При нуле ошибок кнопка неактивна, дополнительные карточки в сетке не создаются.

Неправильный ответ и запрос озвучки до самостоятельного правильного ответа добавляют слово в ошибки. При пустом поле первый Enter только предлагает озвучить, второй фиксирует подсказку и запускает звук; кнопка «Озвучить ответ» работает так же. Повторные ошибки и подсказки не дублируют слово. Пропущенные слова добавляются при завершении подхода. Озвучка после правильного ответа и автоматическая озвучка не создают ошибку. Oxford и IT используют общую логику учёта ошибок, повторения и прогресса.

Для удаления слова из ошибок достаточно одного самостоятельного правильного ответа — в обычной тренировке или в режиме повторения. Новая ошибка или подсказка снова добавляет слово в ошибки; исправление после показанного или озвученного ответа в том же подходе не засчитывается. Для самостоятельного повторения после подсказки нужно начать новый подход. Повторение содержит до 20 слов с ошибками, сохраняет порядок и результаты при перезагрузке; список слов в этом режиме показывает оставшиеся ошибки выбранного раздела. После отработки всех ошибок следующий подход недоступен, можно выбрать обычную тему.

Ошибки хранятся в `vocabulary.mistakes` как пары `[устойчивый ключ слова, 0]`; формат пар сохранён для совместимости. Для Oxford ключом служит строковый ID, для IT с прежними числовыми ID — сочетание темы и слова, совпадающее с ключом накопленного прогресса. Нумерация IT может меняться при сборке словаря, поэтому порядок повторения дополнительно сохраняется в `reviewOrder` по устойчивым ключам; результаты такого подхода восстанавливаются по ним. При загрузке старые записи с одним успешным подходом удаляются из ошибок, поскольку уже удовлетворяют новому правилу. В памяти используется `Map`, в `localStorage` — массив пар; слова, переводы и примеры не дублируются. Удалённые из словаря ключи отбрасываются. Из старых сохранений восстанавливаются известные ошибки последнего подхода, включая IT; прежние запросы озвучки восстановить нельзя. Сброс отметок «Пройдено» не удаляет ошибки.

Только для Oxford под переключателем наборов есть фильтр «Все / A1 / A2 / B1 / B2». После выбора уровня можно переключить режим «Только этот» или «Этот и выше» (по умолчанию). Например, A2 в первом режиме оставляет только A2, во втором — A2, B1 и B2. На кнопке текущей темы диапазон показан словами «A2 и выше». Фильтр обновляет количество слов и скрывает пустые темы и подтемы. Уровень и режим применяются при выборе темы и сохраняются вместе с тренировкой. Закрытие окна без выбора темы не прерывает текущий подход. В IT фильтра нет, его слова и тренировки от Oxford не зависят.

В окне результатов словаря кнопка «Тренировать ошибки» запускает повторение оставшихся ошибок текущей темы с сохранением активного уровня Oxford. Она доступна после обычной тренировки и после повторения ошибок; при отсутствии ошибок неактивна. Кнопки «Следующий подход» в этом окне нет; начать тему заново можно из основной формы тренировки.

Во время словарной тренировки и в её окне результатов кнопка «Следующая тема» начинает новый подход в следующей подтеме текущего набора, в порядке окна выбора. При тренировке целой темы переключение идёт между целыми темами. Уровень Oxford сохраняется, пустые разделы пропускаются; после последнего раздела открывается первый. Если другой подходящей темы нет, кнопка недоступна. Из тренировки всего набора кнопка открывает его первую доступную подтему.

Состав слов и уровни взяты из [Oxford 3000 by CEFR level](https://www.oxfordlearnersdictionaries.com/external/pdf/wordlists/oxford-3000-5000/The_Oxford_3000_by_CEFR_level.pdf). Базовые русские переводы взяты из [открытого набора под лицензией MIT](https://github.com/voothi/20260715190122-oxford-3000-5000) и дополнены исправлениями для этого тренажёра. Копия лицензии находится в `scripts/oxford/sources/LICENSE`. Источники и исправления хранятся в `scripts/oxford/`; для воспроизводимой сборки выполните `python3 scripts/oxford/build_oxford.py`, затем `node build.js`. Определения и примеры Oxford не копируются.

Исходники подборки: `vocabulary/oxford_*.json`. Поля раздела: `id`, `collection`, `topic`, `subtopic`, `source`, `words`. Каждое новое значение слова получает постоянный строковый `id` (например, `oxford:apple:noun`), а также `level` и `partOfSpeech`. Разные подтемы имеют разные `id`, даже если название родительской темы совпадает. После редактирования выполните `npm run build-vocab`: сборка сохраняет метаданные и проверяет уникальность идентификаторов. `js/vocabulary-catalog.js` строит дерево разделов без копирования карточек.

### Модули

- `app.js` — подключение режимов, общие элементы интерфейса, обработчики событий и сборка снимка прогресса.
- `js/*-mode.js` — логика грамматики, словаря, Shadowing и теории. Зависимости передаются явно при создании режима.
- `js/vocabulary-picker.js` — выбор наборов, тем и уровней, карточки и отображение прогресса. Временные фильтры выбора отделены от активной тренировки.
- `js/session-results.js` — отображение и закрытие окна результатов; не меняет оценки или состояние подхода.
- `js/learning-data.js` — темы, теория и переводы; `questions.js` и `vocabulary.js` — сгенерированные базы упражнений.
- `js/activity.js` — отложенные действия. При смене режима или вопроса таймеры отменяются; отменённые callbacks игнорируются.
- `js/speech.js` — синтез речи, выбор голоса и отмена озвучки. Распознавание речи находится в `js/shadowing-mode.js`.
- `js/progress.js` — общий запуск и подсчёт результатов подхода, чтение и запись `localStorage`. Сохранён ключ `english-grammar-trainer.progress.v2` и совместимость с сохранённым прогрессом остальных режимов.

Скрипты подключаются по порядку в `index.html`; сборщик и установка npm-зависимостей не нужны. Настройки озвучки грамматики и словаря независимы.

## Проверки

Нужен Node.js 18 или новее:

```bash
npm test
```

Тесты загружают скрипты из `index.html` и проверяют переключение режимов, таймеры, озвучку, восстановление прогресса и обработчики распознавания речи. DOM, часы и речевые API имитируются; реальный микрофон и качество распознавания проверяются вручную в браузере.
