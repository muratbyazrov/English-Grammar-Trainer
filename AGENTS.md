# Работа с проектом

- Для ориентации используй [ARCHITECTURE.md](ARCHITECTURE.md): там указано, где менять каждый вид поведения.
- Ищи нужные функции через `rg` и читай связанные участки; не загружай целиком сгенерированные базы ради изменения интерфейса.
- Новый подход запускай через `start*Session` своего режима; общий сброс находится в `createSessionScoring().start`.
- Сохраняй совместимость `localStorage`, устойчивых ключей слов и восстановленных подходов.
- Запускай проверки по области изменения, перечисленные в карте проекта. Для рефакторинга нескольких режимов запускай `npm test`.
