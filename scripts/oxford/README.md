# Уточнения переводов и синонимы Oxford

`card-overrides.json` содержит редакторские правки по устойчивым ID карточек.
Разрешены только поля `translation` и `answers`: идентификаторы, уровни,
части речи и примеры сохраняются.

- В `translation` уточняем выбранный смысл в скобках. Одинаковый русский
  перевод не означает, что английские слова взаимозаменяемы.
- В `answers` явно перечисляем допустимые синонимы для указанного смысла.
  Первым остаётся слово самой карточки. Формы с другим значением или частью
  речи не добавляем автоматически. Допустимые синонимы имеют вес `1`.
- При правильном ответе тренажёр показывает остальные допустимые варианты
  в окне «Можно также…», даже если пользователь ввёл основное слово карточки.
  Окно ждёт кнопки «ОК, дальше» или Enter; таймер и окончание озвучки
  не переводят на следующее слово.

Исходный импорт иногда использовал перевод прилагательного для существительного
или наречия. Такие случаи исправлены отдельными записями по ID, например
`high` как наречие — «высоко», как существительное — «максимум».
Уточнения обозначают выбранное значение, а не все возможные употребления слова.

Список слов и уровней остаётся в `sources/official.tsv`, исходный словарь —
в `sources/translations.tsv`. `seed.json` хранит исходные 60 карточек;
редакторские правки применяются поверх них при генерации.

`topic-ids.json` закрепляет ID и имена дополнительных тем. Новые темы получают
новые ID; существующие нельзя перенумеровывать при изменении состава слов.
Части речи разбираются целыми обозначениями (через запятую или `/`): `adv.`
не считается `v.`. Тематические группы по смыслу сохраняют приоритет.
Сохранённый подход Oxford завершается в прежнем порядке даже после переноса
карточек; новый подход использует исправленный состав темы. Прогресс и ошибки
остаются привязаны к устойчивым ID слов.

Для проверки отдельных значений использованы материалы Cambridge:
[shall](https://dictionary.cambridge.org/us/grammar/british-grammar/shall),
[following](https://dictionary.cambridge.org/dictionary/english/following),
[sure](https://dictionary.cambridge.org/us/dictionary/english/sure),
[dear](https://dictionary.cambridge.org/dictionary/english/dear).

После правок последовательно выполнить:

```sh
python3 scripts/oxford/build_oxford.py
npm run build-vocab
node --test tests/vocabulary-catalog.test.js tests/vocabulary-mistakes.test.js tests/vocabulary-alternatives.test.js
```

Обновить версию `vocabulary.js` в `index.html`. Сгенерированные файлы
`vocabulary/oxford_*.json` и `vocabulary.js` сохраняются в репозитории.
